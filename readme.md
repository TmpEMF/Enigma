# 赛博恩尼格玛机

这是一个在控制台运行的恩尼格玛机的模拟程序.

---

## 编译与运行

### 编译

在程序目录中使用
```
gcc main.c -o enigma
```

### 运行

```bash
./enigma
```

## 使用方法

1. 设置转子

在提示`Set Rotors >`时通过键入数字按"左-中-右"顺序选择3个转子,
输入数字的取值范围是$\left[1, 5\right]$, 分别代表转子I, II, ..., V.
例如, 输入`5 1 4`代表依次选择转子V, 转子I, 转子IV.

2. 设置转子的初始位置

在提示`Initialize Rotors >`时通过键入数字按"左-中-右"顺序设定转子的初始位置,
输入数字的取值范围是$\left[1, 26\right]$, 分别代表字母A, B, ..., Z.
例如, 输入$04 09 24$代表转子的起始位置分别为D, I, X.

3. 设置插板

将依次提示`Set the Plugboard I >`至`Set the Plugboard X`, 共10对.
每对需要连续输入两个字母, 表示将两个字母相互连接以实现互换.

> 注意: 目前没有实现重复性检查.

4. 正式使用

此时程序进入主循环并提示`Content >`,
允许输入**只包含字母**的字符串, 程序将输出加/解密后的结果(恒为大写字母).
若含有其他字符, 程序会输出`Content Error`并再次期待输入.

5. 退出

在`Content >`下输入`;;`~~奇怪的符号~~以退出程序.
